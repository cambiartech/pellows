# UI bar — keep this while we build

**Reference:** this Join/Login standard (split layout, step progress, real validation, password eye toggle). Patterns on [Mobbin](https://mobbin.com/) / Airbnb / Dimension.

| Do | Don’t |
|----|--------|
| Field-level errors + focus rings | Silent fail / bland grey boxes only |
| One job per step / section | Dump every field on one screen |
| Clear primary CTA | Competing buttons |
| Password show/hide (eye) | Password without visibility control |
| Real visual on auth/marketing | Empty flat panels |

Apply to host wizard, import hub, search, and chat as we touch them.
